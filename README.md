# Online Resume Builder

A full-stack web application to create professional resumes with live preview and PDF export.

## Tech Stack
- **Frontend:** React.js + Vite + Tailwind CSS
- **Backend:** Node.js + Express.js
- **Database:** MySQL
- **PDF Export:** jsPDF + html2canvas
- **Auth:** bcryptjs

## Features
- User registration & login
- Resume data entry with live preview
- 10 templates across 5 categories
- PDF download
- Save resumes to MySQL
- Admin dashboard with CSV reports

## Setup

### Backend
cd backend
npm install
node server.js

### Frontend
cd client
npm install
npm run dev
